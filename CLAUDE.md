# Market Primer

A static site (`index.html`, served by GitHub Pages) that explains each day's Indian stock market news to a complete beginner.

- Daily briefings are written by a Claude Code routine following `automation/daily-briefing.md` exactly.
- `briefings/index.json` is generated by `scripts/validate.py`. Never edit it by hand.
- `python3 scripts/validate.py` must print `OK` before any commit.
- The site never calls any AI API. No keys or secrets belong in this repo.
